# Planificador de Tareas · País de las Maravillas

## 1. Descripción del proyecto

Planificador de Tareas es una aplicación web responsive construida con HTML5, Bootstrap 5 y JavaScript. Permite crear tareas (nombre, descripción, fecha de entrega y estado), validarlas antes de guardarlas y verlas como tarjetas o como lista, con filtros por estado y un resumen de avance. Incluye frases de ánimo, música ambiental y una ambientación inspirada en el País de las Maravillas.

**Tareas incluidas**
- Tarea 1: wireframes implementados con Bootstrap.
- Tarea 2: componente Tarjeta de Tarea y componente Lista de Tareas.
- Tarea 3: validación del formulario con `validFormFieldInput(data)` y alertas de error.
- Tarea 4: clase `TaskManager` (`js/taskManager.js`) y botón para marcar y desmarcar una tarea como completada.
